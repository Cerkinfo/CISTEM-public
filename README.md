# CISTEM 
### Centralized Inventory and Supply Tracking for Event Management
Le C.I.S.T.E.M est une plateforme développée et utilisée par le Cerkinfo lors du FOSDEM pour aider à la gestion logistique avant et pendant l'événement.

Cette branche sert de relais pour publier sur gh-pages les pages statiques de la plateforme. Les pages dynamiques et code serveur sont run sur une machine durant le week-end cible et étendent le domaine de ces pages.

Le code source de ces pages statiques, dynamiques et code serveur sont sur un repository privé du même nom.
